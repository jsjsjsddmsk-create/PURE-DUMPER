# PURE DUMPER V24

## Run locally or on Render Web Service

Requirements: Node.js 20 or newer.

Install dependencies:
npm install

Start:
npm start

Render settings:
- Service type: Web Service
- Build command: npm install
- Start command: npm start
- Root directory: leave blank

## Project files

- package.json
- server.js
- index.html

Keep these files in the repository root unless server.js is configured to use a different path.

## Notes

This project can inspect publicly accessible website resources only. It cannot retrieve private server-side source code, bypass authentication or access controls, or guarantee complete results for sites that block automated requests or render content dynamically. Do not use it to access data you do not own or have permission to inspect.
